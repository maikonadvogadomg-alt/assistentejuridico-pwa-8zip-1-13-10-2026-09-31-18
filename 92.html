📋 Guia do Projeto Modular

Documentador de Projetos — estrutura, arquivos e script de criação automática

🌳 Estrutura de Pastas
documentador/ ├── index.html ← ponto de entrada, chama tudo │ ├── css/ │ ├── base.css ← cores, fontes, variáveis │ ├── layout.css ← header, grid, containers │ ├── components.css ← botões, badges, cards │ └── tabs.css ← sistema de abas │ ├── js/ │ ├── state.js ← dados globais do projeto │ ├── db.js ← banco de dados local (Dexie) │ ├── loader.js ← lê ZIP e HTML importados │ ├── analyzer.js ← detecta tecnologias e problemas │ ├── builder.js ← monta as telas com os dados │ ├── viewer.js ← visualiza código dos arquivos │ ├── report.js ← gera relatório e exportação │ └── app.js ← inicializa tudo │ └── libs/ ├── jszip.min.js ← lê arquivos ZIP └── dexie.min.js ← banco de dados local
📄 O que cada arquivo faz
Arquivo Tipo Função
index.html HTML Esqueleto da página. Chama todos os CSS e JS na ordem certa.
css/base.css CSS Variáveis de cor, fontes, reset, scrollbar, spinner e utilitários.
css/layout.css CSS Header fixo, área principal, drop zone, loading, cards e grids.
css/components.css CSS Botões, badges, lista de arquivos, árvore, problemas e código.
css/tabs.css CSS Sistema completo de abas de navegação com animação.
js/state.js JS Objeto global STATE com todos os dados do projeto aberto. Compartilhado entre todos os módulos.
js/db.js JS Banco de dados local com Dexie (IndexedDB). Salva e carrega histórico de projetos.
js/loader.js JS Lê arquivos ZIP (via JSZip) e HTML. Controla drag & drop e sistema de abas.
js/analyzer.js JS Detecta tecnologias, dependências, APIs externas, CDNs e problemas no código.
js/builder.js JS Monta todas as telas: stats, techs, deps, árvore, problemas, plano e relatório.
js/viewer.js JS Abre e exibe o conteúdo de qualquer arquivo do projeto com botão de copiar.
js/report.js JS Gera relatório completo para IA e exporta como arquivo .TXT.
js/app.js JS Inicializa tudo, registra eventos globais e verifica se as libs carregaram.
libs/jszip.min.js LIB Biblioteca para ler arquivos ZIP no navegador. Baixar do CDN.
libs/dexie.min.js LIB Biblioteca para banco de dados local (IndexedDB). Baixar do CDN.

🚀 Como usar o script
1
Escolha seu sistema acima e clique no botão para copiar o script.
2
Windows CMD: Aperte Win + R, digite cmd e pressione Enter.
PowerShell: Aperte Win + X e escolha Windows PowerShell.
Mac/Linux: Abra o Terminal.
3
Cole o script com Ctrl+V (ou Cmd+V no Mac) e pressione Enter.
4
A pasta documentador/ será criada no local onde o terminal estiver aberto, com todos os arquivos e subpastas prontos.
5
Baixe as duas libs na pasta libs/:
• jszip.min.js → cdnjs.cloudflare.com/ajax/libs/jszip/3.10.1/jszip.min.js
• dexie.min.js → cdnjs.cloudflare.com/ajax/libs/dexie/3.2.4/dexie.min.js
6
Abra o arquivo index.html no navegador e o projeto estará funcionando! 🎉
